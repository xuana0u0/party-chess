# 派对飞行棋 · Party Flight Chess

基于经典飞行棋结构的**网页版多人派对游戏**，定位「运气 + 策略 + 知识」三重博弈。

## 玩法

- **四阵营热座对战**：绿 / 蓝 / 黄 / 红四家，同屏轮流操作（本地单机 / 同屏热座）。
- **掷骰前进**：踩中技能格触发效果，踩中决斗格发起答题对决。
- **答题小游戏**：内置 **198 题公考速答题库**（数字推理 / 数学运算 / 言语理解 / 判断推理 / 常识判断），答得快、答得对的玩家占优。
- **积分商店**：决斗积分可在商店兑换道具，扭转战局。

## 技术

- **单文件 HTML5 Canvas**，零外部依赖、无需后端服务器。
- 棋盘、素材、题库全部内联，直接打开 `index.html` 即玩。

## 运行方式

- 本地：双击 `index.html` 用浏览器打开即可。
- 静态托管：扔到任意静态托管（GitHub Pages / WorkBuddy 发布 / 对象存储 + CDN）即生成一个可分享链接，别人点开就能玩。

## 当前状态

## 题库维护

- `_gen_exam.js`：按套路参数化生成 / 扩题。
- `_verify_exam.js`：公式重算 + 歧义扫描，校验题库答案正确性。

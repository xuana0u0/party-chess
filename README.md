# 派对飞行棋 · Party Flight Chess

基于经典飞行棋结构的**网页版多人派对游戏**，定位「运气 + 策略 + 知识」三重博弈。

同一个游戏的**两个版本**，各自独立成目录、互不干扰：

| 版本 | 目录 | 形态 | 怎么跑 |
|---|---|---|---|
| 同屏热座版 | `hotseat/` | 单文件 HTML5 Canvas，零依赖、无后端 | 双击 `hotseat/index.html` 即玩 |
| 房间码联机版 | `online/` | 单文件前端 + 一个零依赖 Node 房间服务器 | `cd online && node server.js` |

## 玩法

- **四阵营对战**：绿 / 蓝 / 黄 / 红四家，同屏轮流操作（热座版）或跨设备各持一端（联机版）。
- **掷骰前进**：踩中技能格触发效果，踩中决斗格发起答题对决。
- **答题小游戏**：内置 **198 题公考速答题库**（数字推理 / 数学运算 / 言语理解 / 判断推理 / 常识判断），答得快、答得对的玩家占优。
- **决斗小游戏**：14 款（角斗士棋 / 数独 / 逻辑填字 / 犯罪X / 华容道 / 公考速答 …）。
- **积分商店**：决斗积分可在商店兑换道具，扭转战局。

## 同屏热座版（`hotseat/`）

一台电脑上几个人轮流操作，四家同屏。

- 单文件、零外部依赖，棋盘 / 素材 / 题库全部内联，直接双击 `index.html` 开玩。
- 静态托管：扔到任意静态托管（GitHub Pages / 对象存储 + CDN）即生成一个可分享链接。
- 冻结版本 **v0.135**（1,009,385 字节）。
- 题库维护脚本也在本目录：
  - `_gen_exam.js`：按套路参数化生成 / 扩题。
  - `_verify_exam.js`：公式重算 + 歧义扫描，校验题库答案正确性。
    ⚠ 它读的是**当前工作目录**下的 `index.html`，所以要先 `cd hotseat` 再跑。

## 房间码联机版（`online/`）

跨设备在线对战：房主建房拿到 4 位房间码，其他人输码加入，2~4 人开局。

- `online/index.html` —— 联机版前端（v0.209，1,525,495 字节）。
- `online/server.js` —— 房间服务器，纯 Node 内置模块，**零 npm 依赖**。只做三件事：**房间码分配、成员管理（含换房主）、事件转发**，不含任何游戏逻辑；下行 SSE、上行 POST JSON，断线重连按事件序号补发。
- `online/zpix.ttf` —— 像素字体（7.2 MB）。@font-face 首选本地这份，jsDelivr 只是兜底。**别漏掉它**：不带上，部署后一旦 CDN 不可达，全站会掉成微软雅黑、像素风尽失。

### 本地怎么跑

```bash
cd online
node server.js          # → http://localhost:8787/
```

端口取 `PORT` 环境变量，默认 8787。

### 部署到服务器要注意

- **`online/` 是自包含的部署单元**：整个目录拷到任意装了 Node 的机器上，`node server.js` 就能跑。
- 需要一台**常驻 Node 进程**的服务器（最低配 VPS 即可）。静态托管（GitHub Pages 等）跑不了它 —— 页面能打开，但建不了房、连不上。
- 走反向代理时记得给 SSE 关掉缓冲（响应头已有 `X-Accel-Buffering: no`；nginx 侧再加 `proxy_buffering off`），否则房间事件会被攒着不发。
